# 045. 시트의 상품 이름만 적으면 Gemini가 소개 문구 써 주기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
A열에 상품 이름을 적으면 B열에 쇼핑몰에 쓸 만한 두 문장짜리 소개 문구를 Gemini가 채워 줍니다.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `상품명`, B1에 `소개 문구` 라고 적고 A2부터 상품 이름을 적습니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 `GEMINI_API_KEY` 를 저장합니다.
5. 함수 선택 칸에서 `writeDescriptions` 를 고르고 **실행**, 권한을 허용합니다.
6. B열에 소개 문구가 채워집니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
