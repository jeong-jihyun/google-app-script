# 056. "문의" 라벨 메일에 AI가 답장 초안을 만들어 두기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
Gmail에서 "문의" 라벨을 붙인 읽지 않은 메일마다 AI가 답장 초안을 만들어 임시보관함에 넣어 줍니다. 보내기는 내가 확인한 뒤 직접 누릅니다.

## 따라 하기
1. Gmail에서 `문의` 라벨을 만들고, 답장 초안이 필요한 메일에 붙입니다.
2. [script.new](https://script.new) 를 열어 새 Apps Script 프로젝트를 만듭니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `draftReplies` 를 고르고 **실행**, 권한(Gmail)을 허용합니다.
6. Gmail 임시보관함에 답장 초안이 생깁니다. 읽고 고친 뒤 보내세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
