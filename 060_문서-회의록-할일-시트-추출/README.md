# 060. 회의록 문서에서 AI가 할 일과 담당자를 뽑아 시트에 적기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
회의록 문서를 읽고 "할 일 / 담당자 / 기한"을 AI가 찾아 시트에 한 줄씩 정리합니다. 문서에 없는 정보는 "미정"으로 적어요.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 이 시트 주소의 `/d/` 와 `/edit` 사이 긴 글자(시트 ID)를 복사해 둡니다.
3. [script.new](https://script.new) 를 열어 새 Apps Script 프로젝트를 만듭니다.
4. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
5. 코드 맨 위 `DOC_ID`(회의록 문서 ID)와 `SHEET_ID`(시트 ID)를 바꿔 넣습니다.
6. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
7. 함수 선택 칸에서 `extractTasks` 를 고르고 **실행**, 권한을 허용합니다.
8. 시트의 `할일` 탭에 할 일 / 담당자 / 기한이 한 줄씩 쌓입니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
