# 063. 드라이브 문서 하나를 AI가 핵심 5줄로 줄여 내게 메일로 보내기 (AI 시리즈 7회차)

## 무엇을 하는 예제인가요?
드라이브 문서 하나를 AI가 핵심 5줄로 줄여 내게 메일로 보내기. 쉬운 말로 AI(Claude)에게 일을 시키는 간단한 자동화입니다.

## 따라 하기
1. [script.new](https://script.new) 를 열어 새 파일을 만듭니다(이미 열어 둔 파일이면 **확장 프로그램 → Apps Script**).
2. 준비: 열어 둔 문서 주소의 `/d/` 와 `/edit` 사이 긴 글자가 문서 ID입니다. 복사해 코드의 `DOC_ID` 에 넣습니다.
3. Apps Script 화면에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 아래 "비밀값 저장 방법"대로 `CLAUDE_API_KEY` 를 저장합니다.
5. 위쪽 함수 선택 칸에서 `mailSummary` 을 고르고 **실행** 을 누릅니다.
6. 결과: 내 메일함에 5줄 요약이 도착합니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
