# 115. 시트의 '양식' 탭을 오늘 날짜 이름의 새 탭으로 복사하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
'양식' 탭을 그대로 복사해 탭 이름을 오늘 날짜(예: 2026-10-29)로 붙여 줍니다. 매일 같은 표를 새로 쓰는 경우에 편합니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 시트 아래 탭 이름을 `양식` 으로 바꾸고 원하는 표 모양을 만들어 둡니다.
3. **확장 프로그램 → Apps Script** 에서 `code.gs` 를 붙여 넣고 저장합니다.
4. `copyTemplateToToday` 를 고르고 **실행** → 권한을 허용합니다.
5. 오늘 날짜 이름의 새 탭이 생깁니다. 같은 날 다시 실행하면 안내창만 뜹니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
