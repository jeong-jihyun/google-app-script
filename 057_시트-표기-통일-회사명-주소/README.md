# 057. 들쭉날쭉한 회사 이름을 AI가 하나로 맞춰 주기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
"(주)가나다", "가나다 주식회사", "가나다㈜"처럼 제각각인 이름을 AI가 하나의 표기로 맞춰 옆 칸에 적어 줍니다. 원래 값은 지우지 않아요.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `원래 이름`, B1에 `통일한 이름`을 적고 A2부터 이름을 적습니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `normalizeNames` 를 고르고 **실행**, 권한을 허용합니다.
6. B열에 "주식회사 가나다" 같은 통일된 이름이 채워집니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
