# 018. 드라이브 사진을 Gemini가 보고 설명 달기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
드라이브 폴더에 올린 사진을 Gemini에게 보여 주고, 사진 설명(대체 텍스트)을 한 줄로 받아 시트에 정리합니다. 사진 정리나 웹사이트 이미지 설명에 쓸 수 있습니다.

## 따라 하기
1. 드라이브에 폴더를 만들고 사진(JPG/PNG) 몇 장을 올립니다. 주소창의 폴더 ID(`folders/` 뒤쪽 글자)를 복사합니다.
2. 새 구글 시트 → **확장 프로그램 → Apps Script** 에 `code.gs`를 붙여 넣습니다.
3. 스크립트 속성에 `GEMINI_API_KEY`(키)와 `IMAGE_FOLDER_ID`(폴더 ID)를 저장합니다.
4. 함수 `describeImages` 를 선택하고 **실행** → 드라이브 권한 허용.
5. "사진설명" 탭에 파일 이름, 링크, 설명이 쌓입니다. (한 번에 5장까지)

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
