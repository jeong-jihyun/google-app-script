# 001. Claude API 호출 기본 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
구글 앱 스크립트에서 Claude에게 질문을 보내고, 돌아온 답을 로그에 보여 줍니다.
이후 AI 예제들의 가장 기본이 되는 "AI에게 물어보기" 함수(`askClaude`)입니다.

## 따라 하기
1. 구글 시트를 새로 만듭니다. (주소창에 `sheets.new` 입력)
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 왼쪽 파일 목록의 `코드.gs` 안 내용을 모두 지우고 `code.gs` 내용을 붙여 넣습니다.
4. API 키 저장하기 (코드에 직접 쓰지 않습니다)
   - 왼쪽 톱니바퀴(**프로젝트 설정**) 클릭
   - 맨 아래 **스크립트 속성** → **스크립트 속성 추가** 클릭
   - 속성: `CLAUDE_API_KEY` / 값: 본인의 Claude API 키 → **스크립트 속성 저장**
5. 위쪽 함수 선택 칸에서 `testAskClaude` 를 고르고 **실행** 을 누릅니다.
6. 처음에는 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 순서로 누릅니다.
7. 아래 **실행 로그**에 Claude의 답이 나오면 성공입니다.
