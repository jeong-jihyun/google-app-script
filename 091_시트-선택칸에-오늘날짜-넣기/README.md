# 091. 시트에서 고른 칸에 오늘 날짜 한 번에 넣기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
선택한 칸(여러 칸도 가능)에 오늘 날짜를 한 번에 적어 주는 메뉴를 만듭니다. 날짜를 일일이 치지 않아도 됩니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 시트 탭을 새로고침(F5)하면 위쪽에 **내 도구** 메뉴가 생깁니다. (처음엔 Apps Script 화면에서 `onOpen` 을 한 번 **실행** 해도 됩니다.)
4. 날짜를 넣을 칸을 드래그로 고르고 **내 도구 → 선택한 칸에 오늘 날짜** 를 누릅니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
