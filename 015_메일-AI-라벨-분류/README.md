# 015. 받은 메일을 AI로 분류해 Gmail 라벨 붙이기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
안 읽은 메일을 AI가 "업무 / 결제·청구 / 광고 / 기타" 중 하나로 분류하고, 해당 Gmail 라벨을 자동으로 붙여 줍니다. 메일은 읽음 처리되지 않습니다.

## 따라 하기
1. Apps Script를 열고(`script.google.com` → 새 프로젝트) `code.gs`를 붙여 넣습니다.
2. `CLAUDE_API_KEY`를 스크립트 속성에 저장합니다.
3. 함수 `labelMailsByAI` 를 선택하고 **실행** → Gmail 권한(읽기·라벨 수정) 허용.
4. Gmail 왼쪽 목록에 `AI/업무` 같은 라벨이 생기고 메일에 붙습니다.
5. 자동으로 돌리려면 **트리거 → 시간 기반 → 시간 단위 타이머 → 1시간마다** 로 `labelMailsByAI` 를 추가하세요.

> 메일 내용이 AI 서버로 전송됩니다. 민감한 메일이 많다면 사용을 피하세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
