# 027. 주제만 말하면 구글 폼 설문 질문을 AI가 만들기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
"신입 사원 교육 만족도"처럼 주제만 적으면, AI가 질문 6개를 만들어 **구글 폼** 으로 바로 만들어 줍니다.

## 따라 하기
1. **script.google.com** 에 들어가 **새 프로젝트** 를 누릅니다.
2. `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 코드 맨 위 `SURVEY_TOPIC` 의 글을 원하는 주제로 바꿉니다.
4. 함수 `createSurveyForm` 을 선택하고 **실행** → 폼·드라이브 권한 허용.
5. 실행 기록(로그)에 나온 **수정 주소**로 들어가 질문을 다듬고 공유하세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
