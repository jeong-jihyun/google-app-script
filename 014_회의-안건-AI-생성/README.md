# 014. 캘린더 회의 일정에 AI 안건 메모 달기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
내일 있는 캘린더 일정 중 제목에 "회의"가 들어간 일정을 찾아, AI가 만든 추천 안건(체크리스트)을 일정 설명란에 적어 줍니다.

## 따라 하기
1. 구글 시트(또는 script.google.com의 새 프로젝트)에서 Apps Script를 엽니다.
2. `code.gs`를 붙여 넣고 `CLAUDE_API_KEY`를 저장합니다.
3. 구글 캘린더에 내일 날짜로 "주간 회의" 같은 일정을 하나 만들어 둡니다.
4. 함수 `addAgendaToTomorrowMeetings` 를 선택하고 **실행** → 캘린더 권한 허용.
5. 캘린더에서 그 일정을 열면 **설명**에 추천 안건이 들어 있습니다.
6. 매일 저녁 자동으로 하고 싶다면 **트리거 → 트리거 추가 → 시간 기반 → 일 단위 타이머 → 오후 6~7시**.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
