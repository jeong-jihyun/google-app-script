# 114. 구글 문서 맨 아래에 '작성일: 오늘 날짜' 한 줄 넣기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
문서 맨 아래에 오늘 날짜와 시간이 적힌 줄을 추가합니다. 실행할 때마다 한 줄씩 늘어나서 수정 기록 대신 쓸 수 있습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 문서([docs.new](https://docs.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장** 합니다.
3. `addDateLine` 을 고르고 **실행** → 권한을 허용합니다.
4. 문서로 돌아가 맨 아래에 '작성일' 줄이 생겼는지 확인합니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
