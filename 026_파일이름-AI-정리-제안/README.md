# 026. 드라이브 파일 이름을 AI가 깔끔하게 제안하기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
폴더 안 파일 이름이 "새 문서 (3) 최종_진짜최종" 처럼 어지러울 때, AI가 더 알아보기 쉬운 이름을 **제안만** 해서 시트에 적어 줍니다. 파일 이름은 바꾸지 않으니 안심하세요.

## 따라 하기
1. 정리할 **구글 드라이브 폴더**를 열고 주소창의 `folders/` 뒤 긴 글자(폴더 ID)를 복사합니다.
2. 구글 시트를 만들고 **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣습니다.
3. 코드 맨 위 `FOLDER_ID` 의 따옴표 안에 폴더 ID를 붙여 넣습니다.
4. `CLAUDE_API_KEY` 를 저장하고 `suggestFileNames` 를 **실행** → 권한 허용.
5. "이름제안" 탭에 **현재 이름 | 제안 이름 | 파일 링크** 가 생깁니다. 마음에 드는 것만 직접 바꾸세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
