# 054. 회의 일정 제목만 보고 AI가 안건 문서를 만들어 주기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
내일 캘린더에 있는 제목에 "회의"가 들어간 일정마다, AI가 안건 초안(목적·논의할 것·준비할 것)을 구글 문서로 만들어 줍니다.

## 따라 하기
1. [script.new](https://script.new) 를 열어 새 Apps Script 프로젝트를 만듭니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
4. 함수 선택 칸에서 `makeAgendas` 를 고르고 **실행**, 권한(캘린더·문서)을 허용합니다.
5. 내일 일정 중 "회의"가 들어간 일정마다 내 드라이브에 `안건_일정제목` 문서가 생깁니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
