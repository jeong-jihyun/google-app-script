# 044. 구글 문서 내용을 읽고 AI가 발표 슬라이드 초안 만들기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
문서를 읽고 핵심만 뽑아, 제목과 글머리표가 들어 있는 새 구글 슬라이드(5장 안팎)를 자동으로 만듭니다.

## 따라 하기
1. `docs.new` 로 새 문서를 만들고 발표로 만들고 싶은 글을 붙여 넣습니다.
2. **확장 프로그램 → Apps Script** 를 누르고 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
4. 함수 선택 칸에서 `makeSlidesFromDoc` 를 고르고 **실행**, 권한을 허용합니다.
5. 문서 화면에 슬라이드 주소가 알림으로 뜹니다. 눌러서 확인하세요.
6. 첫 장이 제목 칸 모양과 다르면 슬라이드에서 직접 다듬으면 됩니다. (초안이에요!)

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
