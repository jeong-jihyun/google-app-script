# 096. 시트에 적은 이름대로 드라이브 폴더 여러 개 만들기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
A열에 폴더 이름을 적어 두면 내 드라이브에 그 이름의 폴더를 한 번에 만들어 줍니다. 이미 있는 이름은 건너뜁니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. A열 1행부터 아래로 만들 폴더 이름을 적습니다. (예: 2026-11월, 2026-12월)
4. `makeFolders` 를 고르고 **실행** 을 누른 뒤 [drive.google.com](https://drive.google.com) 에서 확인합니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
