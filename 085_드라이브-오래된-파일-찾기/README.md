# 085. 드라이브 폴더에서 오래 안 쓴 파일 찾아 목록 만들기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
정한 폴더 안에서 마지막 수정이 90일 넘은 파일을 찾아 시트에 이름·수정일·주소를 적어 줍니다. 파일을 지우지는 않고 목록만 만듭니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `listOldFiles` 을 고르고 **실행** 을 누릅니다.
4. 드라이브에서 폴더를 열고 주소창의 `folders/` 뒤 글자를 복사해 `FOLDER_ID` 에 붙여 넣습니다. 목록이 적힐 빈 시트에서 실행하세요.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
