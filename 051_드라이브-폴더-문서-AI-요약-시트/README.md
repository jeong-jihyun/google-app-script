# 051. 드라이브 폴더의 구글 문서를 AI가 한 줄씩 요약해 시트에 모으기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
드라이브 폴더 안의 구글 문서를 하나씩 읽고, 제목과 두 줄 요약을 시트에 정리합니다. 문서가 많을 때 "무슨 문서였지?" 하는 일을 줄여 줘요.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 코드 맨 위 `FOLDER_ID` 에 요약할 드라이브 폴더 주소의 마지막 긴 글자(`folders/` 다음 부분)를 붙여 넣습니다.
4. 왼쪽 톱니바퀴 → 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `summarizeFolder` 를 고르고 **실행**, 권한을 허용합니다.
6. 시트에 `문서요약` 탭이 생기고 문서마다 요약이 한 줄씩 쌓입니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
