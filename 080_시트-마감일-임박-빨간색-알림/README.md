# 080. 마감일이 3일 이내로 다가온 줄을 빨갛게 칠하고 알려 주기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
A열 할 일, B열 마감일을 적어 두면 마감이 3일 이내인 줄을 빨간 배경으로 칠하고, 몇 건인지 메일로 알려 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1 "할 일", B1 "마감일" 을 적고 2행부터 내용을 채웁니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. `highlightDeadlines` 를 선택해 **실행** 합니다.
5. 왼쪽 **트리거(시계 아이콘) → 트리거 추가** → 실행할 함수 `highlightDeadlines`, 이벤트 소스 시간 기반 → 일 단위 타이머 → 오전 8시~9시 → **저장** 을 누릅니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
