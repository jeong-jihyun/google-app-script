# 058. 시트 칸에서 =번역() 처럼 AI를 바로 부르는 나만의 함수 만들기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
시트 칸에 `=AI번역(A2, "영어")` 라고 쓰면 AI가 번역해서 그 칸에 보여 주는 나만의 함수를 만듭니다. 한 번 가져온 번역은 저장해서 같은 요청은 다시 부르지 않습니다.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 스크립트 속성에 `GEMINI_API_KEY` 를 저장합니다(아래 안내).
4. 시트로 돌아와 A2에 한국어 문장을 적고, B2에 `=AI번역(A2, "영어")` 를 입력한 뒤 Enter를 누릅니다.
5. 처음 한 번 "권한이 필요합니다" 메시지가 나오면 **허용**을 누르세요.
6. 잠시 뒤 B2에 번역된 문장이 나타납니다. 언어 자리에 "일본어" 등을 써 보세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini (Google AI Studio에서 발급) API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
