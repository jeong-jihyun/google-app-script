# 052. 고객 후기가 좋은 말인지 나쁜 말인지 AI가 분류하기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
시트 A열에 적은 후기 글을 읽고 B열에 "긍정 / 부정 / 보통" 중 하나와 짧은 이유를 적어 줍니다. 후기가 많을 때 분위기를 빨리 알 수 있어요.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `후기`, B1에 `분류`, C1에 `이유`를 적고 A2부터 아래로 후기를 적습니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `classifyReviews` 를 고르고 **실행**, 권한을 허용합니다.
6. B열과 C열이 채워집니다. 이미 채운 줄은 건너뜁니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
