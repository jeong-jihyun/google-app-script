# 053. 폼에 답이 들어오면 AI가 정중한 답장 메일을 자동으로 보내기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
구글 폼에 누가 답을 제출하면, 내용을 읽은 AI가 정중한 감사 답장을 써서 그 사람 메일로 보내 줍니다. 폼에는 "이메일 주소 수집"이 켜져 있어야 해요.

## 따라 하기
1. `forms.new` 로 새 폼을 만들고, 설정에서 **응답 → 이메일 주소 수집**을 켭니다. 질문 한두 개(예: 문의 내용)를 추가합니다.
2. 폼 오른쪽 위 점 세 개(⋮) → **스크립트 편집기**를 누릅니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `createTrigger` 를 고르고 **실행**, 권한을 허용합니다. (제출 때마다 자동 실행되게 해 줍니다)
6. 폼을 직접 한 번 제출해 보면 입력한 메일로 답장이 옵니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
