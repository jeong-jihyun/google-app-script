# 005. 리뷰 감성분석 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
상품 후기나 댓글을 AI가 읽고 **긍정 / 부정 / 중립** 으로 나누고, 이유를 한 줄로 적어 줍니다.
10건씩 묶어서 보내기 때문에 빠르고 비용도 적게 듭니다.

## 따라 하기
1. 새 구글 시트에서 A1 `리뷰`, B1 `감정`, C1 `이유` 를 적습니다.
2. A2부터 후기를 적습니다. 예) `배송이 빨라서 좋아요`, `포장이 엉망이었어요`
3. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣습니다.
4. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `GEMINI_API_KEY` 를 저장합니다.
5. 함수 `analyzeSentiment` 를 선택하고 **실행** → 권한 창에서 **허용** 합니다.
6. B, C열이 채워집니다.

## 참고
이미 B열에 값이 있는 행은 다시 분석하지 않습니다. 다시 하고 싶으면 B, C열을 지우고 실행하세요.
