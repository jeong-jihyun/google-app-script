# 128. 날짜 옆에 'D-며칠' 남은 일수 자동 계산하기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
A열에 날짜가 있으면 B열에 오늘 기준 남은 일수(D-3, D-day, D+2)를 적어 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다. A열에 날짜를 몇 개 적어 두세요(2행부터).
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 위쪽에서 실행할 함수 `fillDday` 를 고르고 **실행** 버튼을 누릅니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: B열에 D-5, D-day, D+2 같은 표시가 들어갑니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
