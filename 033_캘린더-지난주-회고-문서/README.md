# 033. 지난주 캘린더로 AI가 주간 회고 문서 쓰기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
지난 7일 동안의 캘린더 일정을 모아 AI가 "한 일 / 잘한 점 / 다음 주에 신경 쓸 점" 으로 정리한 회고 문서를 만들어 줍니다.

## 따라 하기
1. `script.new` 를 주소창에 입력해 새 Apps Script 프로젝트를 엽니다.
2. `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 함수 `weeklyReview` 를 선택하고 **실행** → 권한 허용(캘린더, 문서).
4. 로그에 나온 문서 주소를 눌러 확인합니다.
5. (선택) 왼쪽 시계 모양 **트리거 → 트리거 추가** 에서 `weeklyReview` / 시간 기반 / 주 단위 / 월요일 아침을 고르면 매주 자동으로 만들어집니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
