# 030. 공부한 내용으로 AI가 퀴즈 만들기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
시트에 공부한 내용을 적으면 AI가 객관식 퀴즈 3문제와 정답을 만들어 "퀴즈" 탭에 정리합니다. 복습용으로 좋아요.

## 따라 하기
1. 구글 시트 `Sheet1` 의 A1 칸에 공부한 내용을 길게 붙여 넣습니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다.
3. 함수 `makeQuiz` 를 선택하고 **실행** → 권한 허용.
4. "퀴즈" 탭에 **문제 | 보기1~4 | 정답 번호** 가 만들어집니다.
5. 정답이 맞는지 꼭 확인하세요. AI도 틀릴 수 있어요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
