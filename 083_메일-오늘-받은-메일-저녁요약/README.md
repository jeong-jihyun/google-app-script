# 083. 오늘 받은 메일 제목을 저녁에 한 통으로 받기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
매일 저녁 오늘 받은 메일의 보낸 사람과 제목을 모아 내게 한 통의 메일로 보내 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `setDailyTrigger` 을 고르고 **실행** 을 누릅니다.
4. `setDailyTrigger` 를 한 번 실행하면 매일 저녁 6시쯤 메일이 옵니다. 먼저 `eveningMailSummary` 를 직접 실행해 메일이 오는지 확인해 보세요.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
