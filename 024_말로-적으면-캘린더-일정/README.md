# 024. "내일 3시 치과" 말로 적으면 캘린더 일정 만들기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
시트에 "다음 주 화요일 오후 2시에 팀 회의 1시간"처럼 평소 말투로 적으면, AI가 날짜·시간을 찾아 구글 캘린더에 일정을 만들어 줍니다.

## 따라 하기
1. 구글 시트 A1에 `일정 문장` 이라고 적고, A2부터 일정 문장을 한 줄씩 적습니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 함수 `addEventsFromSheet` 를 선택하고 **실행** → 시트·캘린더 권한 허용.
4. 내 기본 캘린더에 일정이 생기고, 시트 B열에 "등록 완료"가 적힙니다.
5. 날짜가 맞는지 캘린더에서 꼭 확인하세요. AI가 날짜를 잘못 읽을 수 있어요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
