# 141. 고른 칸의 합계와 평균을 알림창으로 보기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
고른 숫자 칸의 합계, 평균, 개수를 알림창으로 바로 보여 줍니다. 수식을 따로 쓰지 않아도 됩니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다. (script.new 로 만든 단독 프로젝트라면 이 단계는 생략)
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 시트에 숫자를 적고 마우스로 숫자 칸을 끌어서 고른 뒤 `showSum` 을 실행합니다. (편집기 실행 시 시트 화면에서 칸이 골라진 상태여야 합니다.)
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 알림창에 개수·합계·평균이 뜹니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
