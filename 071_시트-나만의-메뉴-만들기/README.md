# 071. 시트를 열면 위쪽에 나만의 메뉴 만들기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
시트 위쪽 메뉴 줄에 "내 도구" 메뉴를 만들고, 누르면 선택한 칸을 지우거나 오늘 날짜를 넣어 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 시트 화면으로 돌아가 **새로고침(F5)** 합니다.
4. 위쪽에 생긴 **내 도구** 메뉴를 눌러 항목을 골라 봅니다. 처음엔 권한 창이 뜰 수 있습니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
