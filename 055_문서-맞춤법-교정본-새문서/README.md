# 055. 내 글의 맞춤법을 AI가 고쳐 새 문서로 만들어 주기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
지금 열어 둔 문서의 맞춤법과 띄어쓰기를 AI가 고쳐서, 원본은 그대로 둔 채 "교정본" 새 문서를 만들어 줍니다.

## 따라 하기
1. `docs.new` 로 새 구글 문서를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 스크립트 속성에 `CLAUDE_API_KEY` 를 저장합니다(아래 안내).
4. 문서에 글을 몇 문단 적어 둡니다.
5. 함수 선택 칸에서 `makeProofread` 를 고르고 **실행**, 권한을 허용합니다.
6. 내 드라이브에 `제목_교정본` 문서가 생깁니다. 원본과 비교해 보세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
