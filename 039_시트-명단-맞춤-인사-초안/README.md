# 039. 명단에 있는 사람마다 맞춤 인사 메일 초안 만들기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
시트에 이름·이메일·한마디를 적어 두면, 사람마다 내용에 맞는 인사 메일 초안을 AI가 써서 Gmail 임시보관함에 만들어 줍니다. 보내기 전에 직접 읽어 보고 보낼 수 있어요.

## 따라 하기
1. `sheets.new` 로 새 시트를 만들고 1행에 `이름 | 이메일 | 전하고 싶은 말` 을 적습니다.
2. 2행부터 사람 이름, 이메일, 전하고 싶은 말(예: 지난 행사에 와 줘서 고마워요)을 적습니다. 테스트는 내 이메일로 하세요.
3. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다.
4. `makeGreetingDrafts` 를 선택하고 **실행** → 권한 허용.
5. Gmail **임시보관함**에 메일이 만들어집니다. 읽어 보고 직접 보내세요. (자동으로 보내지 않아요)

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
