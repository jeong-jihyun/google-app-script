# 076. "영수증" 라벨 메일의 첨부파일을 드라이브 폴더에 저장하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
Gmail에서 "영수증" 라벨을 붙인 메일의 첨부파일을 드라이브의 "영수증 모음" 폴더에 모아 저장합니다. 한 번 저장한 메일은 다시 저장하지 않습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. Gmail에서 **영수증** 이름의 라벨을 만들고 저장하고 싶은 메일에 붙입니다.
2. [script.new](https://script.new) 를 열어 새 프로젝트를 만듭니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 함수 선택 칸에서 `saveAttachments` 를 고르고 **실행** 합니다.
5. 드라이브에 "영수증 모음" 폴더가 생기고 첨부파일이 들어갑니다. 원하면 트리거를 일 단위로 걸어 둡니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
