# 082. 매주 월요일 시트를 통째로 백업 복사하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
매주 월요일 아침에 지금 시트를 '백업_날짜' 이름으로 드라이브에 복사해 둡니다. 실수로 지워도 되돌릴 수 있어요.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `setWeeklyTrigger` 을 고르고 **실행** 을 누릅니다.
4. `setWeeklyTrigger` 를 **한 번만** 실행하면 매주 월요일 오전 8시에 `backupSheet` 가 자동으로 돌아갑니다. 바로 시험하려면 `backupSheet` 를 직접 실행해 보세요. 백업본은 내 드라이브 첫 화면에 생깁니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
