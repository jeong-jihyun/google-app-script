# 007. AI 번역 시트 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
A열에 한국어 문장을 적으면, B열에 영어, C열에 일본어 번역이 자동으로 채워집니다.
메뉴 버튼 한 번으로 실행됩니다.

## 따라 하기
1. 새 구글 시트에서 A1 `한국어`, B1 `English`, C1 `日本語` 를 적습니다.
2. A2부터 번역할 문장을 적습니다.
3. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 저장합니다.
4. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `CLAUDE_API_KEY` 를 저장합니다.
5. 함수 `onOpen` 을 선택하고 **실행** → 권한 창에서 **허용** 합니다.
6. 시트 탭을 새로고침하면 위쪽 메뉴에 **AI 도구** 가 생깁니다.
7. **AI 도구 → 번역 실행** 을 누르면 B, C열이 채워집니다.

## 바꿔 쓰기
`'영어와 일본어'` 부분과 JSON 형식의 `en`, `ja` 를 바꾸면 다른 언어도 가능합니다.
