# 103. 특정 사람이 보낸 메일에 라벨을 자동으로 붙이기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
지정한 보낸 사람의 메일에 '중요사람' 라벨을 붙여 줍니다. 한 번 실행하면 이미 있는 메일에 붙고, 트리거를 만들면 매시간 자동으로 붙습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [script.google.com](https://script.google.com) 에 들어가 **새 프로젝트** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 코드 위쪽 `SENDER` 를 라벨 붙일 사람의 메일 주소로 바꿉니다.
4. `labelFromSender` 를 고르고 **실행** 을 누른 뒤 권한을 허용합니다.
5. Gmail 왼쪽 목록에 '중요사람' 라벨이 생기고 그 사람 메일이 모입니다.
6. 자동으로 하려면 왼쪽 **트리거(시계 아이콘) → 트리거 추가 → labelFromSender → 시간 기반 → 시간 단위 타이머 → 1시간마다** 로 저장하세요.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
