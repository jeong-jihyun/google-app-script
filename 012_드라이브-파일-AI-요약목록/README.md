# 012. 드라이브 폴더의 문서를 AI로 요약해 목록 만들기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
구글 드라이브 폴더 안의 구글 문서들을 하나씩 읽고, 한 줄 요약을 시트에 목록으로 만들어 줍니다. 파일이 많을 때 "무슨 내용인지" 한눈에 볼 수 있습니다.

## 따라 하기
1. 요약하고 싶은 드라이브 폴더를 열고 주소창에서 폴더 ID를 복사합니다. (`folders/` 뒤쪽 긴 글자)
2. 스크립트 속성에 `FOLDER_ID` 라는 이름으로 그 ID를 저장합니다. (`CLAUDE_API_KEY`와 같은 방법)
3. 함수 선택 칸에서 `summarizeFolderDocs` 를 고르고 **실행** 합니다. 권한(드라이브·문서 읽기)을 허용하세요.
4. "문서요약" 탭에 파일 이름, 링크, 한 줄 요약이 쌓입니다.
5. 한 번에 최대 10개까지만 처리합니다. 더 하려면 `MAX_FILES` 숫자를 늘리세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
