# 117. 내 드라이브의 비어 있는 폴더를 찾아 시트에 목록으로 적기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
파일이 하나도 없는 폴더를 찾아 이름과 주소를 시트에 적어 줍니다. 정리할 폴더를 찾을 때 좋습니다. (지우지는 않고 목록만 만듭니다.)
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 빈 시트를 열고 **확장 프로그램 → Apps Script** 에서 `code.gs` 를 붙여 넣고 저장합니다.
3. `listEmptyFolders` 를 고르고 **실행** → 권한을 허용합니다.
4. 시트에 빈 폴더 이름과 링크가 적힙니다. 처음 200개 폴더까지만 검사합니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
