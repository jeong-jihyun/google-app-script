# 135. 오늘 일정을 아침에 메일로 보내 주기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
구글 캘린더의 오늘 일정을 시간순으로 모아 내 메일로 보냅니다. 트리거로 매일 아침 자동 실행도 가능합니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만듭니다.
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 위쪽에서 실행할 함수 `sendTodayAgenda` 를 고르고 **실행** 버튼을 누릅니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 내 메일함에 오늘 일정 목록이 도착합니다. 왼쪽 시계 아이콘(트리거)에서 '매일 오전'으로 정해 두면 자동으로 옵니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
