# 120. 특정 단어가 들어간 메일을 시트에 목록으로 뽑기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
메일 검색창에 쓰는 검색어(예: 청구서)로 최근 메일을 찾아 날짜·보낸 사람·제목을 시트에 적습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. **확장 프로그램 → Apps Script** 에서 `code.gs` 를 붙여 넣습니다. 6번째 줄 `'청구서'` 를 찾고 싶은 단어로 바꾸고 저장합니다.
3. `mailsToSheet` 를 고르고 **실행** → 권한을 허용합니다.
4. 시트에 최근 30일 안의 해당 메일 목록(최대 50개)이 적힙니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
