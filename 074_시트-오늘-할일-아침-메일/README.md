# 074. 시트에 적어 둔 오늘 할 일을 매일 아침 메일로 받기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
A열 날짜, B열 할 일이 적힌 시트에서 "오늘 날짜"인 줄만 모아 매일 아침 내 메일로 보내 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1 "날짜", B1 "할 일" 을 적고 2행부터 날짜(예: 2026-10-26)와 할 일을 적습니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 함수 선택 칸에서 `sendTodayTasks` 를 고르고 **실행** 해 메일이 오는지 먼저 확인합니다.
5. 왼쪽 **트리거(시계 아이콘) → 트리거 추가** → 실행할 함수 `sendTodayTasks`, 이벤트 소스 시간 기반 → 일 단위 타이머 → 오전 7시~8시 → **저장** 을 누릅니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
