# 140. 시트 위쪽 메뉴에 '내 도구' 메뉴를 만들어 함수 모아 쓰기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
시트를 열 때마다 메뉴 막대에 '내 도구'가 생기고, 메뉴를 눌러 함수를 바로 실행합니다. 코드를 편집기에서 열 필요가 없어집니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 위쪽에서 실행할 함수 `onOpen` 를 고르고 **실행** 버튼을 누릅니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 시트를 새로고침하면 메뉴 막대에 '내 도구'가 생깁니다. 처음에는 `onOpen` 을 한 번 직접 실행하세요.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
