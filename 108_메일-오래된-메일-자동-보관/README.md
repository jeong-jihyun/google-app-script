# 108. 30일 지난 받은편지함 메일을 자동으로 보관 처리하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
받은편지함에서 30일이 지난 읽은 메일을 '보관'으로 옮겨 정리합니다. 메일은 지워지지 않고 검색하면 그대로 찾을 수 있습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [script.google.com](https://script.google.com) 에 들어가 **새 프로젝트** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. `archiveOldMail` 을 고르고 **실행** → 권한 허용을 누릅니다.
4. Gmail 받은편지함이 깔끔해집니다. (지우는 게 아니라 보관이니 안심하세요.)
5. 자동으로 하려면 **트리거 → 트리거 추가 → archiveOldMail → 시간 기반 → 일 단위 타이머** 로 저장합니다.
6. 일수를 바꾸려면 코드의 `DAYS` 숫자를 고치세요.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
