# 020. 주제만 적으면 AI가 글 초안 문서를 만들어 주기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
시트에 주제와 글의 분위기를 적으면, AI가 글 초안을 쓰고 새 구글 문서로 만들어 링크를 시트에 남깁니다.

## 따라 하기
1. 새 구글 시트의 1행에 **주제 | 분위기 | 문서 링크** 를 적고, 2행부터 예: `겨울철 건강관리 | 친근하게` 처럼 적습니다. (C열은 비워 둡니다)
2. **확장 프로그램 → Apps Script** 에 `code.gs`를 붙여 넣고 `CLAUDE_API_KEY`를 저장합니다.
3. 함수 `createDraftDocs` 를 선택하고 **실행** → 문서·드라이브 권한 허용.
4. C열에 새로 만들어진 구글 문서 링크가 들어갑니다. 내 드라이브에서도 찾을 수 있습니다.
5. AI 초안은 꼭 읽고 사실 확인 후 사용하세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
