# 105. 드라이브 폴더 안 파일 이름 앞에 날짜 붙이기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
폴더 안 모든 파일의 이름 앞에 `2026-10-28_` 처럼 오늘 날짜를 붙입니다. 이미 날짜가 붙은 파일은 건너뜁니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [script.google.com](https://script.google.com) 에 들어가 **새 프로젝트** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 날짜를 붙일 폴더를 드라이브에서 열고 주소창의 `folders/` 뒤 글자(폴더 ID)를 복사합니다.
4. 코드의 `FOLDER_ID` 에 붙여 넣습니다.
5. `addDatePrefix` 를 고르고 **실행** → 권한 허용을 누릅니다.
6. 드라이브 폴더에서 파일 이름이 바뀐 것을 확인합니다. (되돌리려면 이름을 직접 고쳐야 하니 처음엔 연습 폴더에서 해 보세요.)


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
