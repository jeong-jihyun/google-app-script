# 022. 받은 메일 중요도를 AI가 점수로 매기기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
최근 받은 메일 10통의 제목과 앞부분을 AI가 읽고, "얼마나 급한지"를 1~5점으로 매겨 시트에 정리합니다. 급한 메일부터 확인할 수 있어요.

## 따라 하기
1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 함수 `scoreRecentMails` 를 선택하고 **실행** → Gmail·시트 권한을 허용합니다.
4. 시트에 "메일점수" 탭이 생기고 **점수 | 보낸 사람 | 제목 | 이유** 가 쌓입니다.
5. 메일 내용은 AI 서비스로 전송됩니다. 개인정보가 많은 메일은 주의하세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
