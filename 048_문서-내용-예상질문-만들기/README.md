# 048. 긴 문서를 읽고 AI가 예상 질문과 답 5쌍 만들기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
문서 맨 아래에 "자주 나올 질문과 답" 5쌍을 붙여 줍니다. 발표 준비나 안내문 만들 때 좋아요.

## 따라 하기
1. `docs.new` 로 새 문서를 만들고 설명하고 싶은 글을 붙여 넣습니다.
2. **확장 프로그램 → Apps Script** 를 열고 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
4. 함수 선택 칸에서 `addQnA` 를 고르고 **실행**, 권한을 허용합니다.
5. 문서 맨 아래에 질문과 답이 추가됩니다. (원래 글은 그대로)

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
