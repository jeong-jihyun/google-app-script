오늘부터 AI 없이 구글 기본 기능만 쓰는 "일상 업무 자동화 시리즈"를 시작했고, 예제 071~080번 10개를 저장소에 올렸습니다.

| 번호 | 제목 | 하는 일 |
|---|---|---|
| 071 | 시트를 열면 위쪽에 나만의 메뉴 만들기 | 나만의 메뉴 |
| 072 | 체크박스를 누르면 완료한 시간이 옆 칸에 자동으로 적히게 하기 | 체크하면 완료 시간 기록 |
| 073 | 시트에서 똑같이 적힌 줄(중복) 찾아 지우기 | 중복 줄 지우기 |
| 074 | 시트에 적어 둔 오늘 할 일을 매일 아침 메일로 받기 | 오늘 할 일 아침 메일 |
| 075 | 구글 폼에 새 답이 들어오면 내게 바로 알림 메일 보내기 | 폼 응답 알림 메일 |
| 076 | "영수증" 라벨 메일의 첨부파일을 드라이브 폴더에 저장하기 | 첨부파일 드라이브 저장 |
| 077 | 시트에 적은 생일을 캘린더에 매년 반복 일정으로 넣기 | 생일 매년 반복 등록 |
| 078 | 드라이브 폴더 안의 파일 이름과 주소를 시트에 목록으로 만들기 | 폴더 파일 목록표 |
| 079 | 시트의 현재 탭을 PDF 파일로 만들어 드라이브에 저장하기 | 시트 탭 PDF 저장 |
| 080 | 마감일이 3일 이내로 다가온 줄을 빨갛게 칠하고 알려 주기 | 마감 임박 줄 색칠·알림 |
