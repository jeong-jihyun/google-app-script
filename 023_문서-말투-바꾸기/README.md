# 023. 구글 문서 말투를 공손하게/친근하게 바꾸기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
지금 열어 둔 구글 문서의 글을 AI가 "공손한 말투" 또는 "친근한 말투"로 바꿔서 새 문서로 만들어 줍니다. 원본은 그대로 남습니다.

## 따라 하기
1. 말투를 바꾸고 싶은 **구글 문서**를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누르고 `code.gs` 를 붙여 넣습니다.
3. `CLAUDE_API_KEY` 를 저장합니다. (아래 안내)
4. 코드 맨 위 `TARGET_TONE` 을 원하는 말투로 바꿉니다. (예: `공손한 존댓말`)
5. 함수 `rewriteTone` 을 선택하고 **실행** → 권한 허용. 실행 기록(로그)에 새 문서 주소가 나옵니다.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
