# 067. 문서에서 고른 어려운 문장을 AI가 쉬운 말로 바꿔 주기 (AI 시리즈 7회차)

## 무엇을 하는 예제인가요?
문서에서 고른 어려운 문장을 AI가 쉬운 말로 바꿔 주기. 쉬운 말로 AI(Claude)에게 일을 시키는 간단한 자동화입니다.

## 따라 하기
1. [docs.new](https://docs.new) 를 열어 새 파일을 만듭니다(이미 열어 둔 파일이면 **확장 프로그램 → Apps Script**).
2. 준비: 구글 문서를 열고 **확장 프로그램 → Apps Script** 를 누릅니다(시트가 아니라 문서에서 여세요).
3. Apps Script 화면에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 아래 "비밀값 저장 방법"대로 `CLAUDE_API_KEY` 를 저장합니다.
5. 위쪽 함수 선택 칸에서 `simplifySelection` 을 고르고 **실행** 을 누릅니다.
6. 결과: 문서를 새로고침하면 `AI` 메뉴가 생깁니다. 글을 드래그로 고르고 **AI → 선택한 글 쉽게 바꾸기** 를 누르면 그 자리에서 바뀝니다. 마음에 안 들면 Ctrl+Z 로 되돌리세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
