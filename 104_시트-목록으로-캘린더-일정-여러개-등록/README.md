# 104. 시트에 적은 일정들을 구글 캘린더에 한 번에 등록하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
시트에 날짜와 제목을 적어 두면 캘린더에 종일 일정으로 한 번에 만들어 줍니다. 등록된 줄에는 '등록완료'가 적혀 중복 등록되지 않습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 시트 1행에 제목을 `날짜 | 일정 제목 | 상태` 로 적습니다. 2행부터 예: `2026-11-05 | 팀 회식`.
4. `addEventsToCalendar` 를 고르고 **실행** → 권한 허용을 누릅니다.
5. 구글 캘린더를 열어 일정이 들어갔는지 확인하세요. C열에 '등록완료'가 표시됩니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
