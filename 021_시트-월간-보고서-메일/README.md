# 021. 시트 숫자를 AI가 읽고 월간 보고 메일 보내기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
시트에 적힌 월별 매출·방문자 같은 숫자를 AI가 읽고, 늘고 줄어든 점을 쉬운 말로 정리해 내 메일로 보내 줍니다.

## 따라 하기
1. 새 구글 시트 1행에 **월 | 매출 | 방문자** 를 적고, 2행부터 숫자를 몇 줄 적습니다. (예: `9월 | 1200000 | 3400`)
2. **확장 프로그램 → Apps Script** 를 누르고 `code.gs` 내용을 붙여 넣습니다.
3. 아래 "비밀값 저장 방법"대로 `CLAUDE_API_KEY` 를 저장합니다.
4. 위쪽 함수 선택 칸에서 `sendMonthlyReport` 를 고르고 **실행** 을 누릅니다. 권한 창이 뜨면 허용합니다.
5. 내 Gmail 받은편지함에 "월간 보고" 메일이 도착합니다.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
