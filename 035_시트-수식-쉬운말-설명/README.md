# 035. 어려운 시트 수식을 AI가 쉬운 말로 풀어 주기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
시트에서 칸을 하나 선택하고 실행하면, 그 칸의 수식이 무슨 뜻인지 AI가 쉬운 한국어로 설명해 옆 칸에 적어 줍니다.

## 따라 하기
1. `sheets.new` 로 새 시트를 만들고 A1 에 `=SUM(B1:B5)` 같은 수식을 적습니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다.
3. 시트로 돌아와 수식이 있는 칸(A1)을 클릭해 선택합니다.
4. Apps Script 에서 `explainFormula` 를 선택하고 **실행** → 권한 허용.
5. 선택한 칸의 오른쪽 칸에 설명이 적힙니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
