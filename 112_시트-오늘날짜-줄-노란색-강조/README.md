# 112. 시트에서 오늘 날짜가 적힌 줄을 노란색으로 칠하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
A열에 날짜가 있는 표에서 오늘 날짜 줄만 노란색으로 칠해 한눈에 찾게 해 줍니다. 어제 칠한 색은 먼저 지웁니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `날짜`, 아래 칸(A2~)에 날짜를 적고 옆 칸에 내용을 적어 둡니다. 오늘 날짜도 하나 넣어 보세요.
3. **확장 프로그램 → Apps Script** 를 열고 기존 코드를 지운 뒤 `code.gs` 를 붙여 넣고 저장합니다.
4. `highlightToday` 를 고르고 **실행** 을 눌러 권한을 허용합니다.
5. 오늘 날짜 줄이 노란색으로 바뀌었는지 확인합니다. 매일 자동으로 하려면 왼쪽 **트리거(시계 아이콘) → 트리거 추가 → 시간 기반 → 일 단위** 로 설정하세요.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
