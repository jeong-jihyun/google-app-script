# 008. 캘린더 일정 AI 정리 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
내 구글 캘린더의 앞으로 7일 일정을 읽고, AI가 "이번 주 브리핑"(총평, 요일별 핵심, 준비할 것)을 써서
내 메일로 보내 줍니다.

## 따라 하기
1. 구글 드라이브에서 **새로 만들기 → 더보기 → Google Apps Script** 를 누릅니다.
2. `코드.gs` 의 내용을 지우고 `code.gs` 를 붙여 넣습니다.
3. 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `GEMINI_API_KEY` 를 저장합니다.
4. 함수 `sendWeeklyBriefing` 을 선택하고 **실행** 을 누릅니다.
5. 권한 창에서 **캘린더 읽기, 메일 보내기** 를 **허용** 합니다. (**권한 검토 → 계정 선택 → 고급 → 이동 → 허용**)
6. 내 받은편지함에 브리핑 메일이 도착합니다.

## 매주 월요일 아침에 자동으로 받기
왼쪽 시계 모양 **트리거 → 트리거 추가** → 함수 `sendWeeklyBriefing`, 이벤트 소스 "시간 기반",
유형 "주 단위 타이머", 요일 "월요일", 시간 "오전 7시~8시" → **저장**.
