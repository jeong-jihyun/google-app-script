# 125. 이번 주 캘린더 일정 개수와 총 시간 세기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
이번 주(월~일) 일정이 몇 개이고 합쳐서 몇 시간인지 계산해 알려줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [script.new](https://script.new)를 열어 새 프로젝트를 만듭니다.
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 위쪽에서 실행할 함수 `weekSummary` 를 고르고 **실행** 버튼을 누릅니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 실행 로그에 이번 주 일정 수와 총 시간이 나옵니다. (종일 일정은 시간 계산에서 빠집니다)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
