# 075. 구글 폼에 새 답이 들어오면 내게 바로 알림 메일 보내기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
구글 폼에 누군가 답을 보내면, 그 내용을 정리해서 내 메일로 바로 알려 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [forms.new](https://forms.new) 로 간단한 설문을 만들고 **응답** 탭에서 **스프레드시트에 연결** 을 눌러 시트를 만듭니다.
2. 그 시트에서 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 왼쪽 **트리거(시계 아이콘) → 트리거 추가** → 실행할 함수 `onFormSubmit`, 이벤트 소스 스프레드시트에서 → 양식 제출 시 → **저장** 을 누릅니다.
5. 폼을 직접 한 번 제출해 보면 메일이 옵니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
