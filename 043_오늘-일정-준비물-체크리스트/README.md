# 043. 오늘 캘린더 일정마다 AI가 준비물 체크리스트 만들어 메일 보내기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
오늘 일정 제목을 보고, 일정마다 챙길 것 2~3가지를 AI가 적어 아침 메일로 보내 줍니다.

## 따라 하기
1. `script.new` 로 새 Apps Script 프로젝트를 엽니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
4. 함수 선택 칸에서 `sendTodayChecklist` 를 고르고 **실행**, 권한(캘린더·메일)을 허용합니다.
5. 내 메일함에 체크리스트가 도착합니다.
6. 매일 아침 받으려면 왼쪽 **트리거 → 트리거 추가**에서 함수 `sendTodayChecklist`, **시간 기반 → 일 단위 → 오전 7~8시**를 고르세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
