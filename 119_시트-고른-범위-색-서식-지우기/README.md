# 119. 시트에서 고른 범위의 색·글꼴 모양만 지우기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
고른 칸의 배경색, 글자색, 굵기 같은 꾸밈만 지우고 내용은 그대로 둡니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. `code.gs` 를 붙여 넣고 **저장** 합니다.
3. 시트에서 색이 칠해진 칸들을 마우스로 고릅니다.
4. Apps Script 화면에서 `clearFormatOnly` 를 고르고 **실행** 합니다. 처음엔 권한을 허용합니다.
5. 시트로 돌아가면 색이 사라지고 글자는 남아 있습니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
