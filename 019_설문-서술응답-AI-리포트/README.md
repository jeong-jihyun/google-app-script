# 019. 설문 서술형 답변을 AI가 요약해 리포트 만들기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
구글 폼 설문의 서술형 답변(응답 시트)을 모두 읽고, AI가 "공통된 의견 3가지와 개선 제안"을 정리해 새 탭에 리포트로 적어 줍니다.

## 따라 하기
1. 구글 폼을 만들고 서술형 질문 하나를 넣은 뒤 폼의 **응답 → 스프레드시트에 연결** 로 시트를 만듭니다. 테스트 응답을 몇 개 제출하세요.
2. 그 응답 시트에서 **확장 프로그램 → Apps Script** 를 열고 `code.gs`를 붙여 넣습니다.
3. `CLAUDE_API_KEY`를 저장합니다.
4. 코드 위쪽 `TARGET_COLUMN` 을 서술형 답이 있는 열 번호로 바꿉니다. (기본 2 = B열)
5. 함수 `makeSurveyReport` 를 선택하고 **실행** → 권한 허용.
6. "AI리포트" 탭에 요약이 생깁니다. 실행할 때마다 새 줄로 쌓입니다.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
