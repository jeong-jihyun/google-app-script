# 031. 시트 오른쪽 창에서 AI에게 바로 물어보기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
시트를 보면서 오른쪽에 작은 창(사이드바)을 열어 AI에게 질문할 수 있습니다. 선택한 칸의 글을 질문에 함께 넣을 수도 있어요.

## 따라 하기
1. 구글 시트를 새로 만듭니다. (`sheets.new`)
2. **확장 프로그램 → Apps Script** 를 열고 `code.gs` 를 붙여 넣습니다.
3. 왼쪽 `+` 버튼 → **HTML** 을 눌러 이름을 `Sidebar` 로 만들고, 아래 "화면 파일" 내용을 붙여 넣습니다.
4. `GEMINI_API_KEY` 를 저장합니다. (아래 방법)
5. 저장 후 시트 화면을 새로고침하면 위쪽에 **AI 도우미** 메뉴가 생깁니다.
6. **AI 도우미 → 질문 창 열기** 를 누르고 권한을 허용합니다.
7. 시트에서 칸을 하나 선택한 뒤 오른쪽 창에 질문을 쓰고 **물어보기** 를 누릅니다.

## 화면 파일
`Sidebar.html` 의 내용을 Apps Script 의 HTML 파일(`Sidebar`)에 붙여 넣으세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
