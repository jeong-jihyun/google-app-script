# 046. 폼 문의가 급한지 AI가 판단해 급하면 바로 메일 알림 받기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
폼에 새 응답이 들어올 때마다 AI가 "급함/보통"을 판단해 시트에 적고, 급함이면 내게 알림 메일을 보냅니다.

## 따라 하기
1. 구글 폼을 만들고 **응답 탭 → 스프레드시트에 연결** 을 눌러 응답 시트를 만듭니다.
2. 응답 시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
5. 왼쪽 시계 모양 **트리거 → 트리거 추가**: 함수 `onFormSubmit`, 이벤트 소스 **스프레드시트에서**, 이벤트 유형 **양식 제출 시** → 저장 → 권한 허용.
6. 폼에 "지금 결제가 안 돼서 업무가 멈췄어요" 같은 글을 제출해 봅니다.
7. 시트 맨 오른쪽 칸에 "급함"이 적히고 알림 메일이 옵니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
