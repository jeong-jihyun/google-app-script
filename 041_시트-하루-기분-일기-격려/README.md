# 041. 시트에 적은 하루 기분 일기에 AI가 따뜻한 한마디 달기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
A열에 오늘 있었던 일을 한두 줄 적으면, B열에 AI가 쓴 짧고 따뜻한 격려 한마디가 들어갑니다.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `오늘 일기`, B1에 `AI 한마디` 라고 적고 A2부터 일기를 한두 줄씩 적습니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
5. 편집기 위 함수 선택 칸에서 `addEncouragement` 를 고르고 **실행**을 누릅니다. 권한 창이 뜨면 허용합니다.
6. 시트로 돌아가면 B열에 한마디가 채워져 있습니다. (이미 채워진 줄은 건너뜁니다)

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
