# 040. 문서에서 고른 문장을 쉬운 말로 풀어 쓰기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
구글 문서에서 어려운 문장을 드래그로 고른 뒤 메뉴를 누르면, 그 아래에 AI가 쉽게 풀어 쓴 문장이 들어갑니다. 계약서·공지문을 읽을 때 좋아요.

## 따라 하기
1. `docs.new` 로 새 문서를 만들고 어려운 문장을 붙여 넣습니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 문서 화면을 새로고침하면 위쪽에 **AI 도우미** 메뉴가 생깁니다.
4. 쉽게 풀고 싶은 문장을 마우스로 드래그해 고릅니다.
5. **AI 도우미 → 선택한 글 쉬운 말로 풀기** 를 누르고 처음 한 번 권한을 허용합니다.
6. 고른 글 바로 아래에 풀이가 들어갑니다. (원래 글은 그대로예요)

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
