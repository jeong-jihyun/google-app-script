# 036. 쓴 글에 어울리는 제목 후보 5개 추천받기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
구글 문서에 쓴 글을 AI가 읽고 제목 후보 5개를 문서 맨 위에 적어 줍니다. 마음에 드는 것만 남기고 지우면 돼요.

## 따라 하기
1. `docs.new` 로 새 문서를 만들고 글을 몇 문단 씁니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. `suggestTitles` 를 선택하고 **실행** → 권한 허용.
4. 문서 맨 위에 "제목 후보" 5개가 들어갑니다.
5. 마음에 드는 제목을 고른 뒤 나머지는 지웁니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
