# 009. AI 메일 답장 초안 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
Gmail에서 `답장필요` 라벨을 붙인 메일에 대해 AI가 답장 초안을 써서 **임시보관함**에 넣어 줍니다.
메일이 자동으로 발송되지는 않습니다. 읽어 보고 고친 뒤 직접 보내면 됩니다.

## 따라 하기
1. Gmail을 열고 왼쪽 **라벨 옆 + (새 라벨 만들기)** 를 눌러 `답장필요` 라벨을 만듭니다.
2. 답장이 필요한 메일을 열고 위쪽 **라벨 아이콘**을 눌러 `답장필요` 를 체크합니다.
3. 구글 드라이브에서 **새로 만들기 → 더보기 → Google Apps Script** 를 누르고 `code.gs` 를 붙여 넣습니다.
4. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `CLAUDE_API_KEY` 를 저장합니다.
5. 함수 `createReplyDrafts` 를 선택하고 **실행** → 권한 창에서 **허용** 합니다.
6. Gmail 왼쪽 **임시보관함**에 답장 초안이 생겼는지 확인합니다.

## 주의
메일 내용이 AI 회사 서버로 전송됩니다. 민감한 메일에는 쓰지 마세요.
