# 029. 슬라이드마다 발표 대본(스피커 노트) 자동 작성 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
구글 슬라이드의 각 장 내용을 AI가 읽고, 말하듯이 읽을 수 있는 발표 대본을 **발표자 노트** 에 적어 줍니다.

## 따라 하기
1. 발표 자료(**구글 슬라이드**)를 엽니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. 함수 `writeSpeakerNotes` 를 선택하고 **실행** → 슬라이드 권한 허용.
4. 슬라이드 아래 **발표자 노트** 칸에 대본이 들어갑니다. 이미 노트가 있는 장은 건너뜁니다.
5. 대본은 초안입니다. 내 말투로 고쳐 쓰세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
