# 032. 보내기 전에 임시보관함 메일을 AI가 검토하기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
Gmail 임시보관함에 쓰다 만 메일들을 AI가 읽고 "말투가 딱딱한 곳", "빠진 정보", "오타" 등을 짚어 줍니다. 결과는 시트에 모이며 메일은 절대 자동으로 보내지 않습니다.

## 따라 하기
1. `sheets.new` 로 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다.
3. Gmail 에 아무 메일이나 쓰다가 보내지 말고 닫아 임시보관함에 둡니다.
4. 함수 `reviewDrafts` 를 선택하고 **실행** → 권한 허용.
5. 시트의 "검토" 탭에 **제목 | 받는 사람 | 검토 의견** 이 쌓입니다.
6. 의견을 참고해 Gmail 에서 직접 고친 뒤 보내세요.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
