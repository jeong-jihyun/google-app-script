# 006. 구글 문서 자동 요약 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
긴 구글 문서를 열고 메뉴 한 번만 누르면, 문서 맨 위에 AI가 만든 요약이 들어갑니다.

## 따라 하기
1. 구글 드라이브에서 **새로 만들기 → Google 문서** 로 문서를 만들고 요약할 글을 붙여 넣습니다.
2. 문서 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
3. `code.gs` 내용을 붙여 넣고 저장(디스크 모양)합니다.
4. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `CLAUDE_API_KEY` 를 저장합니다.
5. 함수 `onOpen` 을 선택하고 **실행** → 권한 창에서 **허용** 합니다.
6. 문서 탭으로 돌아와 새로고침하면 메뉴에 **AI 도구** 가 생깁니다.
7. **AI 도구 → 이 문서 요약하기** 를 누르면 맨 위에 요약이 들어갑니다.

## 주의
되돌리려면 **Ctrl+Z(맥은 Cmd+Z)** 를 누르세요.
