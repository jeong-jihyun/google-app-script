# 146. 새 폴더 만들고 폴더 주소를 시트에 적기 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
드라이브에 새 폴더를 만들고, 그 폴더의 이름과 바로가기 주소를 현재 시트에 적어 둡니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 해당 구글 파일(또는 [script.new](https://script.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다. (script.new 로 만든 단독 프로젝트라면 이 단계는 생략)
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 시트에 연결된 스크립트(확장 프로그램 → Apps Script)에서 `createFolderAndLog` 를 실행합니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 내 드라이브에 폴더가 생기고 시트 맨 아래에 폴더 이름과 주소가 적힙니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
