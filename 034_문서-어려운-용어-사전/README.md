# 034. 문서 속 어려운 낱말을 AI가 쉬운 용어 사전으로 만들기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
열어 둔 구글 문서에서 어려운 낱말을 AI가 골라 쉬운 설명과 함께 시트에 "용어 사전"으로 정리합니다. 전문 자료를 공부할 때 편해요.

## 따라 하기
1. 구글 문서에 어려운 글을 붙여 넣습니다. (`docs.new`)
2. **확장 프로그램 → Apps Script** 를 열고 `code.gs` 를 붙여 넣습니다.
3. `GEMINI_API_KEY` 를 저장합니다.
4. 함수 `makeGlossary` 를 선택하고 **실행** → 권한 허용.
5. 로그에 나온 시트 주소를 눌러 **낱말 | 쉬운 설명** 표를 확인합니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
