# 017. 시트 FAQ를 근거로 답하는 AI 질문 웹페이지 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
시트에 적어 둔 자주 묻는 질문(FAQ)만 근거로 AI가 답하는 간단한 웹페이지를 만듭니다. FAQ에 없는 내용은 "모르겠습니다"라고 답하도록 했습니다.

## 따라 하기
1. 새 구글 시트의 이름을 `FAQ` 탭으로 바꾸고 A열에 질문, B열에 답을 적습니다. (1행은 제목)
2. **확장 프로그램 → Apps Script** 에서 `code.gs`를 붙여 넣고 `CLAUDE_API_KEY`를 저장합니다.
3. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택.
4. 설명 입력, 실행 사용자 **나**, 액세스 권한 **나만**(테스트용) → **배포** → 권한 허용.
5. 나온 **웹 앱 URL**을 열면 질문 입력칸이 보입니다.
6. 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
