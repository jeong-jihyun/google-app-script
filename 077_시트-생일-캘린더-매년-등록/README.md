# 077. 시트에 적은 생일을 캘린더에 매년 반복 일정으로 넣기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
A열 이름, B열 생일(월-일)을 적어 두면, 캘린더에 "○○ 생일" 종일 일정을 매년 반복으로 만들어 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1 "이름", B1 "생일" 을 적고 2행부터 예: `민수` / `2000-03-15` 처럼 적습니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 함수 선택 칸에서 `addBirthdays` 를 고르고 **실행** 합니다. (한 번만 실행하세요. 여러 번 하면 중복됩니다.)
5. Google 캘린더를 열어 생일 일정이 들어갔는지 확인합니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
