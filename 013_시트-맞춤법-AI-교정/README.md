# 013. 시트 문장을 AI로 맞춤법 교정하기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
A열에 적은 문장을 AI가 맞춤법·띄어쓰기에 맞게 고쳐서 B열에 적어 줍니다. 원본은 그대로 남습니다.

## 따라 하기
1. 구글 시트를 새로 만듭니다. (주소창에 `sheets.new` 입력)
2. **확장 프로그램 → Apps Script** 를 열고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
3. 시트의 **A열**에 고치고 싶은 문장을 2행부터 적습니다. (1행은 제목)
4. 먼저 아래 "API 키 저장 방법"대로 키를 저장합니다.
5. 함수 `fixSpelling` 을 선택하고 **실행** 합니다. 권한(스프레드시트 편집)을 허용하세요.
6. **B열**에 교정된 문장이 채워집니다. 이미 B열이 채워진 행은 건너뜁니다.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
