# 003. 안 읽은 메일 AI 요약 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
받은편지함에서 아직 안 읽은 메일 최대 5통을 찾아 AI가 짧게 요약하고,
"메일요약" 시트에 한 줄씩 정리해 줍니다. 메일은 읽음 처리되지 않고 그대로 둡니다.

## 따라 하기
1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `code.gs` 내용을 붙여 넣습니다.
3. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `CLAUDE_API_KEY` 를 저장합니다.
4. 함수 선택 칸에서 `summarizeUnreadMails` 를 고르고 **실행** 을 누릅니다.
5. 권한 창에서 **Gmail 읽기** 권한을 허용합니다. (**권한 검토 → 계정 선택 → 고급 → 이동 → 허용**)
6. 시트 아래쪽에 "메일요약" 탭이 생기고 요약이 쌓입니다.

## 자동으로 돌리고 싶다면
왼쪽 시계 모양 **트리거 → 트리거 추가** → 함수 `summarizeUnreadMails`, 이벤트 소스 "시간 기반", 원하는 간격 선택 → **저장**.

## 주의
메일 내용이 AI 회사 서버로 전송됩니다. 개인정보가 많은 메일에는 쓰지 마세요.
