# 004. 시트 데이터 AI 분류 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
시트 A열에 적힌 고객 문의를 AI가 읽고, B열에 **결제 / 배송 / 사용법 / 기타** 중 하나로 분류해 줍니다.
이미 분류된 칸은 건드리지 않아서 여러 번 실행해도 안전합니다.

## 따라 하기
1. 새 구글 시트를 만들고 A1에 `문의`, B1에 `분류` 를 적습니다.
2. A2부터 아래로 문의 문장을 적습니다. 예) `카드 결제가 두 번 됐어요`, `택배가 아직 안 왔어요`
3. **확장 프로그램 → Apps Script** 를 열고 `code.gs` 를 붙여 넣습니다.
4. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `CLAUDE_API_KEY` 를 저장합니다.
5. 함수 `classifyRows` 를 선택하고 **실행** → 권한 창에서 **허용** 합니다.
6. 시트로 돌아오면 B열에 분류가 채워져 있습니다.

## 바꿔 쓰기
코드 위쪽 `CATEGORIES` 목록의 단어만 바꾸면 나만의 분류표가 됩니다.
