# 094. 별표 표시한 메일을 시트에 목록으로 뽑기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
Gmail에서 별표를 눌러 둔 메일의 날짜·보낸 사람·제목을 시트에 표로 만듭니다. 나중에 처리할 메일을 한눈에 봅니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. Gmail에서 나중에 볼 메일에 별표를 눌러 둡니다.
2. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. `starredToSheet` 를 고르고 **실행** 을 누릅니다. 최근 50개까지 표로 나옵니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
