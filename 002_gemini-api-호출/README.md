# 002. Gemini API 호출 기본 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
구글의 AI인 Gemini에게 질문을 보내고 답을 로그에 보여 줍니다.
001번(Claude)과 같은 방식이라, 두 AI를 나란히 써 보며 비교할 수 있습니다.

## 따라 하기
1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. `코드.gs` 의 내용을 지우고 `code.gs` 내용을 붙여 넣습니다.
3. API 키 저장하기
   - 왼쪽 톱니바퀴(**프로젝트 설정**) 클릭 → 맨 아래 **스크립트 속성 추가** 클릭
   - 속성: `GEMINI_API_KEY` / 값: 본인의 Gemini API 키 → **스크립트 속성 저장**
   - (키는 Google AI Studio 사이트에서 **Get API key** 를 눌러 만들 수 있습니다.)
4. 함수 선택 칸에서 `testAskGemini` 를 고르고 **실행** 을 누릅니다.
5. 권한 창이 뜨면 **권한 검토 → 계정 선택 → 고급 → 이동 → 허용** 을 누릅니다.
6. **실행 로그**에 답이 나오면 성공입니다.
