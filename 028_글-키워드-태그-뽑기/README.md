# 028. 시트 글에서 키워드와 태그 뽑기 (AI 시리즈 3일차)

## 무엇을 하는 예제인가요?
시트에 적은 글(메모, 기사, 후기)에서 핵심 키워드 3개와 한 줄 태그를 AI가 뽑아 줍니다. 나중에 필터로 찾기 쉬워요.

## 따라 하기
1. 구글 시트 1행에 **글 | 키워드 | 태그** 를 적고, A열에 글을 넣습니다.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다. (Gemini 사용)
3. 함수 `extractKeywords` 를 선택하고 **실행** → 권한 허용.
4. B열에 키워드 3개, C열에 `#태그` 형태로 채워집니다.
5. 무료 Gemini 키는 [Google AI Studio](https://aistudio.google.com/apikey) 에서 받을 수 있어요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
