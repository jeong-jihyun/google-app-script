# 059. 가계부 지출 내역을 AI가 식비·교통비 등으로 나눠 주기 (AI 시리즈 6회차)

## 무엇을 하는 예제인가요?
가계부 시트에 "스타벅스 4500원"처럼 적으면 AI가 "식비 / 교통 / 쇼핑 / 문화 / 기타" 중 맞는 항목을 옆 칸에 채워 줍니다.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A1에 `내용`, B1에 `금액`, C1에 `항목`을 적고 A2부터 지출 내용을 적습니다.
3. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 스크립트 속성에 `GEMINI_API_KEY` 를 저장합니다(아래 안내).
5. 함수 선택 칸에서 `classifyExpenses` 를 고르고 **실행**, 권한을 허용합니다.
6. C열에 항목이 채워지고, 이미 채운 줄은 다시 계산하지 않습니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini (Google AI Studio에서 발급) API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
