# 073. 시트에서 똑같이 적힌 줄(중복) 찾아 지우기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
선택한 시트에서 1열 값이 같은 줄이 여러 개면 처음 것만 남기고 나머지를 지웁니다. 이메일 목록 정리에 좋습니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. A열에 이메일이나 이름을 여러 줄 적고, 일부러 같은 값을 몇 개 넣어 둡니다(1행은 제목).
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 함수 선택 칸에서 `removeDuplicates` 를 고르고 **실행** 을 누릅니다.
5. 결과: 같은 값이 중복된 줄이 사라지고, 맨 아래 알림창에 지운 개수가 뜹니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
