# 037. 시트에서 이상한 숫자를 AI가 점검해 메모 달기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
A열에 쌓인 숫자(예: 매출, 방문자 수)를 AI가 훑어보고 평소와 너무 다르거나 입력 실수 같은 값을 짚어 메모로 알려 줍니다.

## 따라 하기
1. `sheets.new` 로 시트를 만들고 A1 부터 A열에 숫자 20개쯤을 넣습니다. 일부러 아주 큰 숫자도 하나 섞어 보세요.
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `GEMINI_API_KEY` 를 저장합니다.
3. `checkNumbers` 를 선택하고 **실행** → 권한 허용.
4. 이상하다고 AI가 말한 줄 번호의 칸에 노란색 칠과 메모가 붙습니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `GEMINI_API_KEY`, 값 = 본인의 Gemini API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
