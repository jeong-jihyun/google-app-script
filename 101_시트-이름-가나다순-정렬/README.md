# 101. 시트의 표를 이름 순서(가나다순)로 한 번에 정렬하기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
첫 번째 열(A열)을 기준으로 표를 가나다순(오름차순)으로 정렬합니다. 첫 줄(제목)은 그대로 둡니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 시트에 제목줄과 데이터를 적어 둡니다(예: A열에 이름, B열에 점수).
4. 위쪽 함수 선택 칸에서 `sortByName` 을 고르고 **실행** 을 누릅니다.
5. A열 기준으로 표가 가나다순으로 바뀝니다. 다른 열 기준으로 하고 싶으면 코드의 `COLUMN = 1` 숫자를 바꾸세요(2는 B열).


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
