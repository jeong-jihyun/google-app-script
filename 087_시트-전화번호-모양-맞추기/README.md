# 087. 시트의 전화번호를 010-1234-5678 모양으로 맞추기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
선택한 칸의 전화번호를 하이픈이 들어간 한 가지 모양으로 통일합니다. 01012345678, 010 1234 5678 모두 같은 모양이 됩니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `fixPhones` 을 고르고 **실행** 을 누릅니다.
4. 전화번호가 적힌 칸들을 선택한 뒤 실행합니다. 길이가 맞지 않는 번호는 건드리지 않습니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
