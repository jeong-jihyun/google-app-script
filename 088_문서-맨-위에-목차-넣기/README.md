# 088. 구글 문서 맨 위에 목차 자동으로 넣기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
문서의 제목(제목1·제목2) 서식을 읽어 맨 위에 클릭 가능한 목차를 넣어 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 문서([docs.new](https://docs.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `addToc` 을 고르고 **실행** 을 누릅니다.
4. 구글 문서를 열고 **확장 프로그램 → Apps Script** 에 붙여 넣어 실행합니다. 문서에 제목 서식(서식 → 단락 스타일 → 제목 1)이 있어야 목차가 채워집니다. 문서를 바꾼 뒤에는 목차를 눌러 새로고침 하세요.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
