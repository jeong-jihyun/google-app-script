# 111. 시트에서 고른 숫자 칸의 합계와 평균 알려주기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
시트에서 마우스로 고른 칸들의 합계, 평균, 개수를 작은 알림창으로 바로 보여 줍니다. 수식을 따로 안 써도 됩니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택칸에서 `showSum` 을 고르고 **실행** 을 누른 뒤 권한을 허용합니다.
4. 시트에서 숫자가 있는 칸 몇 개를 마우스로 끌어 고릅니다.
5. 다시 Apps Script 화면에서 **실행** 을 누르면, 시트에 합계·평균 알림창이 뜹니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
