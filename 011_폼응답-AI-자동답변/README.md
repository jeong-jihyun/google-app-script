# 011. 구글 폼 응답에 AI가 자동 답변 메일 보내기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
구글 폼에 누군가 문의를 제출하면, AI가 내용을 읽고 정중한 답변을 써서 그 사람에게 메일로 보내 줍니다. (처음엔 "임시보관함"에만 저장해서 검토 후 보내는 방식입니다.)

## 따라 하기
### 폼과 연결하기
1. 구글 폼을 만들고 질문을 **"이메일"(짧은 답변)**, **"문의 내용"(장문형)** 순서로 넣습니다. 폼 설정에서 "이메일 주소 수집"을 켜도 됩니다.
2. 폼 편집 화면 오른쪽 위 **⋮(더보기) → 스크립트 편집기** 를 누릅니다.
3. `코드.gs`에 `code.gs` 내용을 붙여 넣고 저장합니다.
4. API 키를 저장합니다. (프로젝트 설정 → 스크립트 속성 추가 → `CLAUDE_API_KEY`)
5. 왼쪽 시계 모양 **트리거 → 트리거 추가**: 함수 `onFormSubmit`, 이벤트 소스 **"양식에서"**, 이벤트 유형 **"양식 제출 시"** → 저장 → 권한 허용.
6. 폼에서 테스트 응답을 한 번 제출해 보세요. 메일 **임시보관함**에 답변이 생기면 성공입니다.
7. 검토 없이 바로 보내고 싶다면 코드의 `SEND_DIRECTLY` 를 `true` 로 바꾸세요.

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
