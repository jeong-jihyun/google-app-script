# 078. 드라이브 폴더 안의 파일 이름과 주소를 시트에 목록으로 만들기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
드라이브 폴더 하나를 정하면 그 안의 파일 이름·종류·수정일·바로가기 주소를 시트에 한 줄씩 정리해 줍니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 드라이브에서 목록을 만들 폴더를 열고 주소창 `folders/` 뒤의 긴 글자(폴더 ID)를 복사합니다.
2. [sheets.new](https://sheets.new) 를 열어 새 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
4. 코드 맨 위 `FOLDER_ID` 의 따옴표 안에 복사한 값을 붙여 넣고 저장합니다.
5. `listFiles` 를 선택해 **실행** 하면 시트에 목록이 채워집니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
