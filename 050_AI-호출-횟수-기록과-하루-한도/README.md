# 050. AI를 부른 횟수를 기록하고 하루 한도를 넘지 않게 막기 (AI 시리즈 5회차)

## 무엇을 하는 예제인가요?
AI를 쓸 때마다 시트에 기록하고, 하루에 정한 횟수(기본 20번)를 넘으면 더 부르지 않습니다. 요금이 갑자기 늘어나는 것을 막아 줘요.

## 따라 하기
1. `sheets.new` 로 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기의 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성에 아래 "API 키 저장 방법"대로 키를 저장합니다.
4. 함수 선택 칸에서 `testSafeCall` 을 고르고 **실행**, 권한을 허용합니다.
5. 시트에 `AI사용기록` 탭이 생기고 호출 기록이 쌓입니다.
6. `DAILY_LIMIT` 숫자를 2로 바꿔 세 번 실행해 보면 한도에서 멈추는 것을 확인할 수 있습니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
