# 107. 구글 문서의 글자 수와 단어 수를 세어 알려주기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
지금 열려 있는 문서의 글자 수(공백 포함·제외)와 단어 수를 알림창으로 보여 줍니다. 과제나 글 분량을 맞출 때 편합니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 문서를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. `countText` 를 고르고 **실행** → 권한 허용을 누릅니다.
4. 문서 화면에 글자 수·단어 수 알림창이 뜹니다.


## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
