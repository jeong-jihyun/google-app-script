# 016. 회의 메모에서 AI로 할 일(액션 아이템) 뽑기 (AI 시리즈 2일차)

## 무엇을 하는 예제인가요?
구글 문서에 대충 적은 회의 메모를 읽고, AI가 "누가 / 무엇을 / 언제까지"로 정리한 할 일 목록을 문서 맨 아래에 붙여 줍니다.

## 따라 하기
1. 새 구글 문서를 만들고(`docs.new`) 회의 메모를 적습니다. 예: "철수가 다음 주 금요일까지 견적서 보내기로 함".
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고 `code.gs`를 붙여 넣습니다.
3. `CLAUDE_API_KEY`를 스크립트 속성에 저장합니다.
4. 함수 `extractActionItems` 를 선택하고 **실행** → 문서 편집 권한 허용.
5. 문서 맨 아래에 "[AI 할 일 정리]" 가 생깁니다.
6. 문서에서 바로 쓰고 싶다면 `onOpen` 이 메뉴 **AI → 할 일 뽑기** 를 만들어 줍니다. (문서를 새로고침하면 보입니다)

## 비밀값(API 키) 저장 방법
API 키 저장: 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
