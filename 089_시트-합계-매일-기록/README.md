# 089. 매일 합계 숫자를 '기록' 탭에 한 줄씩 쌓기 (일상 자동화 시리즈 1회차)

## 무엇을 하는 예제인가요?
'데이터' 탭 B열의 합계를 매일 같은 시각에 '기록' 탭에 날짜와 함께 한 줄씩 남겨 변화를 볼 수 있게 합니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new)) 를 열고 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 **저장(디스크 아이콘)** 을 누릅니다.
3. 위쪽 함수 선택 칸에서 `setLogTrigger` 을 고르고 **실행** 을 누릅니다.
4. 시트 탭 이름을 `데이터` 로 하고 B열에 숫자를 적습니다. `logDailyTotal` 을 직접 실행해 '기록' 탭이 생기는지 보고, `setLogTrigger` 로 매일 밤 11시 자동 실행을 켭니다.

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
