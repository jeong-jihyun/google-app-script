# 010. 시트에서 =AI() 함수 만들기 (AI 시리즈 1일차)

## 무엇을 하는 예제인가요?
엑셀의 `=SUM()` 처럼, 시트 칸에 `=AI("질문")` 이라고 쓰면 AI의 답이 바로 나옵니다.
같은 질문은 저장해 둔 답을 다시 보여 주므로 호출 비용이 줄어듭니다.

## 따라 하기
1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `code.gs` 를 붙여 넣고 저장합니다.
3. **프로젝트 설정(톱니바퀴) → 스크립트 속성 추가** 에서 `GEMINI_API_KEY` 를 저장합니다.
4. 시트로 돌아와 아무 칸에 아래처럼 입력하고 Enter 를 누릅니다.
   - `=AI("대한민국의 수도는?")`
   - A2 칸에 글을 적어 두고 `=AI("한 줄로 요약해 줘: "&A2)`
5. 처음 한 번은 "권한이 필요합니다" 표시가 뜹니다. **액세스 허용** 을 누르고 **허용** 합니다.
6. 잠시 후 칸에 답이 나타납니다.

## 주의
- 칸을 많이 복사하면 호출이 한꺼번에 많아져 느려지거나 제한에 걸릴 수 있습니다. 수십 칸 이내로 쓰세요.
- 칸 내용이 AI 회사 서버로 전송됩니다.
