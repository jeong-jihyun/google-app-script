# 138. 체크박스를 누르면 그 줄이 회색 취소선으로 바뀌는 할 일 목록 (일상 자동화 시리즈 3회차)

## 무엇을 하는 예제인가요?
A열 체크박스를 체크하면 같은 줄의 B열 글자가 회색 + 취소선이 되고, 체크를 풀면 원래대로 돌아옵니다.
AI나 API 키 없이 구글 기본 기능만 쓰는 예제라 비용이 들지 않습니다.

## 따라 하기
1. 구글 시트([sheets.new](https://sheets.new))를 열고 **확장 프로그램 → Apps Script** 를 누릅니다. A열에 체크박스(메뉴 삽입 → 체크박스), B열에 할 일을 적습니다. 저장 후 아래 **onEdit 자동 실행**은 따로 설정이 필요 없습니다.
2. 열린 편집기에서 기존 코드를 지우고 `code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다. 코드 안에 "바꾸세요"라고 적힌 값이 있으면 내 것으로 고칩니다.
3. 위쪽에서 실행할 함수 `onEdit` 를 고르고 **실행** 버튼을 누릅니다.
4. 처음이면 권한 창이 뜹니다. 허용해 주세요.
5. 결과: 체크박스를 누를 때마다 할 일이 완료/미완료 모양으로 바뀝니다. (편집기에서 실행하지 말고 시트에서 체크해 보세요)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요. 내 계정의 파일만 다루는 코드라 안전합니다.
