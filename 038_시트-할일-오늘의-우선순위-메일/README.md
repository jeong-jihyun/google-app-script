# 038. 할 일 목록을 보고 AI가 오늘 우선순위를 메일로 보내기 (AI 시리즈 4회차)

## 무엇을 하는 예제인가요?
시트에 적어 둔 할 일을 AI가 읽고 "오늘 꼭 할 것 3개"를 골라 내게 메일로 보내 줍니다. 매일 아침 자동으로 받도록 설정할 수도 있어요.

## 따라 하기
1. `sheets.new` 로 새 시트를 만들고 A열에 할 일을 한 줄에 하나씩 적습니다. (B열에 마감일을 적어도 좋아요)
2. **확장 프로그램 → Apps Script** 에 `code.gs` 를 붙여 넣고 `CLAUDE_API_KEY` 를 저장합니다.
3. `sendTodayPriority` 를 선택하고 **실행** → 권한 허용(시트, 메일 보내기).
4. 내 메일함에서 "오늘의 우선순위" 메일을 확인합니다.
5. 매일 아침 받으려면 왼쪽 시계 모양 **트리거 → 트리거 추가** → 함수 `sendTodayPriority` / 시간 기반 / 일 단위 / 오전 7~8시를 고릅니다.

## 비밀값(API 키) 저장 방법
왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가** → 속성 `CLAUDE_API_KEY`, 값 = 본인의 Claude API 키 → **스크립트 속성 저장**

(키는 코드에 직접 쓰지 않습니다. 남에게 보여 주지 마세요.)

## 처음 실행할 때
처음 실행하면 "권한 검토" 창이 뜹니다. **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 을 차례로 누르세요.
